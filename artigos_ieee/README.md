# Manuscritos IEEE para Overleaf

Cada arquivo `.tex` é um manuscrito independente no formato `IEEEtran` e usa o
mesmo arquivo `references.bib`. Para compilar no Overleaf, envie toda esta
pasta, abra um dos arquivos `.tex` como documento principal e use `pdfLaTeX`
com `BibTeX`.

Os textos foram deliberadamente redigidos como estudos de caso e propostas de
avaliação: os únicos números reportados são os já observados no projeto (711
células H3, 22 zonas e 609 POIs). Antes de submeter, execute os protocolos de
avaliação descritos e substitua os campos marcados como `TBD` por resultados
reproduzíveis.

Arquivos:

1. `01_legal_aware_recommendation.tex` — recomendação territorial com restrições legais.
2. `02_urban_opportunity_detection.tex` — oportunidade urbana com H3, POIs e Sentinel-2.
3. `03_geospatial_property_valuation.tex` — avaliação imobiliária enriquecida por contexto geoespacial.
